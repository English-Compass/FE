# 스크린샷 디렉토리

이 디렉토리에는 프로젝트의 주요 화면 스크린샷을 저장합니다.

## 필요한 스크린샷

다음 스크린샷 파일들을 이 디렉토리에 추가해주세요:

- `home-dashboard.png` - 홈 대시보드 (학습 분석 차트 포함)
- `study-page.png` - 학습 페이지 (문제 풀이 화면)
- `review-page.png` - 복습 페이지 (틀린 문제 목록)
- `media-page.png` - 미디어 페이지 (OTT 콘텐츠 추천)
- `conversation-page.png` - 대화 연습 페이지
- `mypage.png` - 마이페이지 (프로필 및 통계)
- `landing-page.png` - 랜딩 페이지 (카카오 로그인)
- `add-info-page.png` - 추가 정보 입력 페이지

## 스크린샷 촬영 가이드

1. 각 페이지의 주요 기능이 잘 보이도록 촬영
2. 해상도: 최소 1920x1080 권장
3. 파일 형식: PNG 또는 JPG
4. 파일명: kebab-case 사용 (예: `home-dashboard.png`)
